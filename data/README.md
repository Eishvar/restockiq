# Synthetic dataset: campus kopitiam (AIMST University area, Kedah)

All files are **synthetic**, generated by `generate.py` (fixed seed, reproducible). Menu names and price
levels are modelled on a typical Malaysian kopitiam; popularity shares were noise-perturbed, and every
daily figure is simulated. No real transactions, customers or company records are included.

Period: **2025-10-22 → 2026-10-21 (365 days)**. The app's planning date defaults to 2026-10-22.

| File | Rows | Columns |
|---|---|---|
| `daily_sales.csv` | ~29k | date, item_id, item_name, category, qty, unit_price_rm, net_sales_rm. One row per item per day **when sold** (missing row = 0 sold). |
| `menu_items.csv` | 143 | item_id, name, category, price_rm, launch_date (blank = on menu all year) |
| `ingredients.csv` | 74 | ingredient_id, name, supplier_id, storage, base_uom (g/ml/pcs), pack_uom, pack_size_base, pack_price_rm, shelf_life_days, waste_pct |
| `recipes.csv` | 558 | item_id, item_name, ingredient_id, qty_per_serving (base uom), base_uom |
| `suppliers.csv` | 3 | supplier_id, name, category, delivery_days, lead_time_days, min_order_rm, whatsapp (fake numbers) |
| `inventory.csv` | 74 | ingredient_id, name, qty_base, base_uom, last_purchased_date, counted_on (2026-10-22). Expiry = last_purchased_date + shelf_life_days (from ingredients.csv). Fresh milk, bread and mango are already expired; eggs expire in 2 days (demo cases). |
| `calendar_events.csv` | 29 | type (`period` / `public_holiday` / `local_event`), label (what the forecaster learns per: semester / break / intake …), start_date, end_date, name; includes upcoming dates |
| `reference_forecast.py` | | Validated prototype of the forecaster, backtest and safety-buffer maths. `python reference_forecast.py` prints accuracy (≈13% daily-total WAPE) and buffers. |
| `menu_profile.csv` | 143 | generator input (perturbed popularity shares) |
| `daily_totals.png` | | chart of items sold per day |
| `demo_reports/` | | **Pre-made sales report for Thu 22 Oct 2026** to upload during the demo: `sales_report_2026-10-22.pdf` (253 items, RM 1,779.50) and the same lines as `.csv` (use it if the PDF reader is unavailable). Made by `make_demo_report.py` (own fixed seed, same demand rules as `generate.py`); no other data file changes. Not loaded by the seed. |

Units: quantities are in base units; buy quantities = ceil(need / pack_size_base) packs × pack_price_rm.

Shelf lives (days, editable in the app): ice 1 · fresh chicken, kangkung 2 · noodles 3 · bread, jambu 4 ·
most fruit 5–7 · fresh milk 7 · eggs 14 · sambal paste 30 · garlic 60 · frozen meat/seafood 90 ·
cooking cream 90 · coffee 180 · frozen snacks 180–365 · rice, oil, sauces, tea, Milo 365 · sugar, honey,
soy sauce, canned goods 730.

Regenerate: `python generate.py` (needs numpy, matplotlib).
